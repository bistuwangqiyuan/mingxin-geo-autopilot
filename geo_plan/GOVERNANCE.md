# 铭信 GEO · 治理、合规与自我纠错机制

> 目的：把"白帽合规、数据溯源、月度复盘纠错"固化为可执行制度，做到自我净化、自我完善、
> 自我革新、自我提高。本文件与 `outputs/changelog.md`、复测脚本共同构成治理闭环。

## 一、白帽合规红线（不可逾越）
1. **禁止伪造**：不伪造第三方测评、不刷评论/水军、不雇佣流量、不制造虚假口碑。
2. **禁止欺骗模型**：不做隐藏文字、关键词堆砌、页面 prompt 注入、cloaking（对爬虫与用户展示不同内容）。
3. **禁止冒称**：不冒称未取得的资质/认证，不臆造专利号/证书号；一律采用如实口径。
4. **不贬损同行**：竞品对比只用客观、可核验口径，以各方最新官方信息为准。
5. **数据真实**：对外每一个实测数字都能溯源到 `business_plan/outputs/results.json`（与官网
   company.ts 同源）与签字级/正式版测试报告 R1–R9，且**必须带报告编号**；
   R9 数字必须如实标注华为 Atlas 910B 昇腾平台。

## 二、数据溯源纪律
- **单一事实源**：官网 `site/src/lib/data/company.ts` → 本仓库 `results.json` →
  `geo_plan/outputs/entity_facts.json`。站内外所有内容的关键数值必须与之一致：
  吞吐提升 +29–40%（R2/R3）、TTFT 降 26–32%（R2）、对无外存重算加速 8.6–20×（R2）、
  LMCache 并行读补丁 TTFT 4.1×（R1）、模型加载 6.2–9.3× vs NFS（R9·昇腾）、
  训练 Checkpoint 保存 1.9×（R1）、FX100 满配 ¥371,200（≈¥2,014/TB，厂商口径）。
- **命名沿革**：FX100 历史称谓 AISSD5000/WS5000/GP5000（同一产品）；历史称谓出现时
  必须附 FX100 命名沿革声明，用于消歧与历史检索。
- **品牌消歧**：注明运营主体为铭信（天津）半导体设备有限公司，与其他同名"铭信"企业区分。
- **禁用旧口径**：任何已废弃的旧数字/表述一律不得出现（详见
  `source_audit.check_consistency` 的禁用清单）；发现即判为口径冲突并拒绝发布。
- **数据分级**：A=API 真测（可程序复现），B=人工取证（截图+文本+双人复核）。报告中标注等级，不混淆。
- **预测口径**：所有提升预测标注为"规划假设区间（P10/P50/P90）"，非业绩承诺；系数来源见 `geo_config.py`（G1–G8）。
- **一致性自检**：站外发布前用 `source_audit.check_consistency()` 抽检数值矛盾与旧口径残留；
  发布清单见 `offsite/publish_checklist.md`。
- **站内核查口径**：官网为 Next.js 站点（robots/llms 为路由），核查一律对线上
  `https://mingxinstorage.xyz` 做 HTTP 探测；网络不可用时如实标注 unknown/pending，不编造。

## 三、月度复盘与纠错机制（PDCA）
1. **复测（同口径）**：每月用 `python geo_audit.py` + `python geo_scoring.py` 复测 GVI，与上月对比。
2. **归因（定位环节）**：未达标的模型定位问题在 **抓取层 / 信源层 / 内容层** 哪一环：
   - 抓取层：robots/sitemap/llms.txt 路由是否被该模型爬虫读取？
   - 信源层：该模型偏好的平台是否已覆盖、内容是否一致？（见 `outputs/source_gap.json`）
   - 内容层：答案优先结构、schema、事实密度与报告编号引用是否到位？
3. **纠错（既治标又治本）**：小问题当月处理；结构性问题修订 `geo_config.py` 假设或站内外策略。
4. **留痕**：每轮复盘写入 `outputs/changelog.md`，包含日期、GVI 变化、动作、负责人、下月目标。

## 四、客观检验标准看板（KPI Dashboard）
> 数据来源：`outputs/geo_baseline.json`（复测后刷新）。"目标"为分阶段冲刺值，区间见预测报告；
> 基线以最近一次真实复测为准，不预填数字。

| 指标 | 基线 | 阶段二目标(第6周) | 阶段三目标(第14周) | 数据源 |

| 总体 GVI（0–100） | 以复测为准 | ≥ 12 | ≥ 20 | geo_baseline.overall.gvi |
| 品牌平均被提及率 | 以复测为准 | ≥ 18% | ≥ 28% | overall.mention_rate |
| T1 被提及率（保守 P50） | 以复测为准 | 见预测报告 P2·T1 | 见预测报告 P3·T1 | geo_projection |

## 五、角色与节奏
- **内容**：站内事实页与站外母版改写（一致性优先，实测数字带报告编号）。
- **数据**：每月复测、刷新看板、出具复盘。
- **合规**：发布前红线核对（本文件第一节 + 禁用旧口径清单）。
- 节奏：每月 1 次复测 + 复盘；季度 1 次策略评审（是否上调/下调阶段目标）。
